## Governance

- New ADRs are required for material architecture changes.
- ADRs must include context, decision, alternatives, consequences, implementation impact, security impact, testing impact and adoption impact.
- Superseding an ADR requires a new ADR that explains the migration impact.
- Product Decisions remain higher priority than ADRs.
